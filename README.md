# Iris Flower Classification (CodeAlpha Internship - Task 1)

Predicting the species of an Iris flower from its measurements.

## What I did
- Explored the data and plotted a pairplot
- Compared 4 models: Decision Tree, Random Forest, Logistic Regression, SVM
- Evaluated with a confusion matrix and classification report
- Checked feature importance

## Results
- Decision Tree, Logistic Regression and SVM: about 96.7% accuracy
- Random Forest: 90% accuracy
- Petal length and petal width are the most important features

## Tools
Python, pandas, seaborn, scikit-learn
